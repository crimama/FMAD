# 연구 방향 후보 — Visual Anomaly Detection

작성일: 2026-03-23
단계: 주제 탐색 (Topic Exploration)

---

## 현재 필드 상태 요약

- **MVTec AD 포화**: image AUROC ~99.9% (Dinomaly2). 이 벤치마크에서의 추가 개선은 의미 없음
- **패러다임 전환 진행 중**: per-class → unified multi-class, hand-crafted → foundation model 기반
- **DINOv2 + CLIP/MLLM 조합**이 2024-2025 지배적 트렌드
- 여전히 어려운 문제: logical anomaly, 3D/multimodal, continual learning, real-world deployment

---

## 후보 방향

### 방향 1: Logical Anomaly Detection

**왜 이 방향인가?**
- Structural anomaly (텍스처 결함)는 거의 해결됨 → logical anomaly (구성 요소 누락, 배치 오류)는 SOTA ~96% (SALAD, ICCV 2025)로 여전히 gap 존재
- MVTec LOCO AD가 주요 벤치마크, Real-IAD도 logical anomaly 포함
- Foundation model의 reasoning 능력과 자연스럽게 연결 가능

**가능한 angle:**
- VLM의 compositional reasoning 활용 (단순 feature matching이 아닌 관계/구조 이해)
- Graph-based structural constraint learning
- Normal image의 part-whole 관계를 명시적으로 모델링

**Risk:** SALAD (ICCV 2025)가 이미 strong baseline → 차별화 필요

---

### 방향 2: Zero/Few-Shot AD with Efficient Adaptation

**왜 이 방향인가?**
- 실제 산업 현장에서 새로운 제품마다 대량 데이터 수집 비현실적
- VLM 기반 zero-shot (AnomalyCLIP, AA-CLIP)은 되지만, 정밀도 부족
- Few-shot 시 빠른 adaptation mechanism이 핵심 차별점

**가능한 angle:**
- Test-time adaptation: 몇 장의 정상 이미지로 빠르게 모델 보정
- Prompt tuning + memory bank 하이브리드
- Meta-learning for anomaly-specific feature selection

**Risk:** 경쟁 치열 (CVPR/ICLR 2025에 다수 논문). 차별화 포인트 명확해야 함

---

### 방향 3: Anomaly Reasoning & Explainability with MLLM

**왜 이 방향인가?**
- 탐지만이 아닌 "왜 이것이 anomaly인가" 설명이 실제 산업에서 필수
- MMAD benchmark (ICLR 2025)가 나왔지만, 방법론 자체는 초기 단계
- MLLM의 reasoning을 anomaly detection에 특화시키는 연구가 아직 적음

**가능한 angle:**
- Chain-of-thought anomaly reasoning
- Normal specification을 자연어로 정의하고 이를 기반으로 판별
- Detection + segmentation + explanation을 통합하는 프레임워크

**Risk:** MLLM 자체의 hallucination 문제, 평가 메트릭 미확립

---

### 방향 4: Continual / Incremental Anomaly Detection

**왜 이 방향인가?**
- 공장 라인에서 제품이 추가/변경됨 → 모델도 적응해야 함
- One-for-More (CVPR 2025)가 diffusion 기반으로 시도했지만 아직 초기
- Catastrophic forgetting + anomaly의 one-class 특성이 결합되어 독특한 challenge

**가능한 angle:**
- Parameter-efficient continual adaptation (LoRA-style for AD)
- Replay-free continual learning with feature regularization
- Class-incremental unified AD model

**Risk:** Continual learning 자체가 mature하지 않음, 벤치마크 부족

---

### 방향 5: Multi-Modal (RGB + 3D) Anomaly Detection

**왜 이 방향인가?**
- Real-IAD D3 (CVPR 2025)로 벤치마크 등장
- 3D 데이터의 노이즈 처리, RGB-3D fusion 전략이 아직 미성숙
- 실제 산업 환경에서 3D 센서 보급 확대 중

**가능한 angle:**
- Geometry-aware feature alignment
- 3D noise-robust fusion mechanism
- Depth estimation 기반 pseudo-3D 활용 (실제 3D 센서 없이도)

**Risk:** 데이터셋 접근성, 3D 데이터 처리 인프라 필요

---

### 방향 6: Anomaly Synthesis / Generation for Better Detection

**왜 이 방향인가?**
- Normal 데이터만으로 학습하는 한계를 synthetic anomaly로 보완
- FAST (NeurIPS 2025)가 foreground-aware diffusion 시도
- Logical anomaly에 대한 synthetic generation은 거의 미탐색

**가능한 angle:**
- 구조적 규칙 기반 logical anomaly 합성
- Diffusion model을 활용한 controllable defect generation
- Anomaly-aware contrastive learning with synthetic pairs

**Risk:** Synthetic-real domain gap, 합성 품질이 성능에 직결
