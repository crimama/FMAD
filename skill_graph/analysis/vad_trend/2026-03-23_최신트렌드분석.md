# Visual Anomaly Detection — 최신 트렌드 분석 (2024-2025)

작성일: 2026-03-23
분석 범위: CVPR/ICCV/ECCV/NeurIPS/ICLR/AAAI 2024-2025 + arXiv preprints

---

## 1. 필드 전체 흐름: 3대 패러다임 전환

### 전환 1: Per-Class → Multi-Class Unified
- **과거**: 카테고리마다 독립 모델 학습 (PatchCore, EfficientAD 등)
- **현재**: 단일 모델로 전 카테고리 처리
- **전환점**: **Dinomaly** (CVPR 2025) — 최초로 multi-class 모델이 per-class SOTA와 동등/상회 (MVTec AD 99.6%)
- **의미**: 더 이상 per-class가 우월하다는 가정이 성립하지 않음
- **남은 과제**: 카테고리 160개 이상 스케일에서 10-20% 성능 저하 (Real-IAD Variety)

### 전환 2: Task-Specific → Foundation Model 기반
- **과거**: ImageNet pretrained CNN + task-specific head
- **현재**: DINOv2/CLIP/MLLM 등 대규모 사전학습 모델 직접 활용
- **주요 방법론 계보**:
  - CLIP 기반: WinCLIP → AnomalyCLIP → PromptAD → AA-CLIP → Bayes-PFL
  - DINOv2 기반: Dinomaly → Dinomaly2
  - MLLM 기반: AnomalyGPT → Anomaly-OV → Triad
- **의미**: Feature engineering에서 adaptation engineering으로 무게 중심 이동

### 전환 3: Supervised/Full-Training → Zero/Few-Shot
- **과거**: 대량 정상 이미지로 학습
- **현재**: 0~8장으로도 detection 가능 추구
- **경쟁 격화**: CVPR/ICLR 2025에 10편 이상의 zero/few-shot AD 논문
- **성능 현황**: Zero-shot ~93-95% AUROC (MVTec AD), few-shot(4-shot) ~97%+ 도달
- **의미**: 새 제품에 대한 즉시 적용 가능성 → 실용성 크게 향상

## 2. 방법론 계보별 상세 분석

### 2.1 CLIP 기반 Zero/Few-Shot AD

| 논문 | Venue | 핵심 아이디어 | MVTec AD (I-AUROC) |
|------|-------|-------------|-------------------|
| WinCLIP | CVPR 2023 | Window-level CLIP matching | 91.8% (0-shot) |
| AnomalyCLIP | ICLR 2024 | Object-agnostic prompt learning | 91.5% (0-shot, 17 datasets) |
| PromptAD | CVPR 2024 | Normal-only prompt learning, anomaly margin | 97.3% (4-shot) |
| AdaCLIP | ECCV 2024 | Static + dynamic hybrid prompts | 14 datasets에서 SOTA |
| VCP-CLIP | ECCV 2024 | Visual context prompting (텍스트가 아닌 시각 프롬프트) | 14 datasets |
| AA-CLIP | CVPR 2025 | Anomaly-aware text space 강화 | - |
| Bayes-PFL | CVPR 2025 | Bayesian prompt distribution 학습 | pixel AUROC SOTA |
| IIPAD | ICLR 2025 | Instance-induced prompt generator | few-shot SOTA |
| RareCLIP | ICCV 2025 | Online rarity estimation for zero-shot | - |

**트렌드 요약**:
- Prompt engineering → prompt learning → Bayesian/instance-adaptive prompt로 진화
- Text prompt만으로는 한계 → visual prompt 병행 (VCP-CLIP)
- 핵심 난제: CLIP 자체가 anomaly를 본 적 없어 text-image alignment이 약함

### 2.2 DINOv2 기반 Reconstruction

| 논문 | Venue | 핵심 아이디어 | MVTec AD (I-AUROC) |
|------|-------|-------------|-------------------|
| Dinomaly | CVPR 2025 | DINOv2 + linear attention + noisy bottleneck | 99.6% (multi-class) |
| Dinomaly2 | arXiv 2025 | Full-spectrum unified (2D/3D/multi-view) | 99.9% |
| AnomalyDINO | WACV 2025 | DINOv2 patch-level few-shot matching | few-shot SOTA |

**왜 DINOv2가 강한가**:
- Self-supervised 학습으로 local semantic feature가 매우 풍부
- ImageNet supervised와 달리 class-specific bias가 적음
- Patch-level feature가 anomaly localization에 자연스러운 granularity
- **Dinomaly의 핵심 발견**: 복잡한 구조보다 4가지 essential만으로 충분 (foundation backbone, noisy bottleneck, linear attention, loose reconstruction)

### 2.3 Knowledge Distillation (Teacher-Student)

| 논문 | 핵심 | 특징 |
|------|------|------|
| EfficientAD | 경량 PDN | ms-level latency, 실시간 가능 |
| LA-EAD | Logical anomaly 특화 | LOCO 94.2% |
| AdapTS | Multi-class + continual | 경량 teacher-student |

**트렌드**: 단독 방법보다 foundation model과의 결합/경량화 방향으로 이동

### 2.4 MLLM 기반 Reasoning

| 논문 | Venue | 핵심 |
|------|-------|------|
| AnomalyGPT | AAAI 2024 | Multi-turn dialogue로 anomaly 설명 |
| Anomaly-OV | CVPR 2025 | 125K instruction tuning, zero-shot reasoning |
| Triad | ICCV 2025 | Expert-guided ROI + manufacturing CoT |
| LogicQA | ACL 2025 | VLM으로 logical anomaly 추론 (training-free) |
| MMAD | ICLR 2025 | 39,672 QA benchmark for MLLM 평가 |

**트렌드**: 단순 detection → **reasoning + explanation** 확장. 초기 단계지만 빠르게 성장 중

### 2.5 Diffusion 기반

| 논문 | Venue | 용도 |
|------|-------|------|
| GLAD | ECCV 2024 | Global+local adaptive diffusion reconstruction |
| R3D-AD | ECCV 2024 | 3D point cloud diffusion reconstruction |
| One-for-More | CVPR 2025 | Continual AD with diffusion |
| FAST | NeurIPS 2025 | Foreground-aware anomaly synthesis |
| Anomaly Anything | CVPR 2025 | Promptable anomaly generation |

**트렌드**: Detection 자체보다 **anomaly synthesis/generation** 도구로 활용 비중 증가

### 2.6 Anomaly Synthesis/Generation

| 논문 | Venue | 핵심 |
|------|-------|------|
| RealNet | CVPR 2024 | Strength-controllable diffusion synthesis |
| GLASS | ECCV 2024 | Gradient ascent로 weak defect 합성 |
| AnoGen | ECCV 2024 | Few-shot real anomaly → large-scale generation |
| Anomaly Anything | CVPR 2025 | Text-prompted unseen anomaly generation |
| SeaS | ICCV 2025 | Few-shot separation-sharing generation |
| FAST | NeurIPS 2025 | Foreground-aware diffusion synthesis |

**트렌드**: Cutpaste/Perlin noise → diffusion 기반 realistic synthesis로 진화. Pixel AP +8.66% 개선 보고 (SeaS)

### 2.7 Generalist / Cross-Domain AD

| 논문 | Venue | 핵심 |
|------|-------|------|
| InCTRL | CVPR 2024 | In-context residual, 3개 도메인 통합 |
| ResAD | NeurIPS 2024 (Spotlight) | Residual feature distribution → class-agnostic |
| MetaUAS | NeurIPS 2024 | One-prompt meta-learning, pure vision |
| GeneralAD | ECCV 2024 | Distorted feature attention |
| NAGL | NeurIPS 2025 | Normal+abnormal reference guided |
| UniVAD | CVPR 2025 | Training-free unified few-shot |
| ADPretrain | NeurIPS 2025 | AD 전용 pretraining |
| INP-Former | CVPR 2025 | Single image에서 normal prototype 추출 |

**트렌드**: "하나의 모델로 모든 도메인/카테고리"가 최종 목표. ResAD의 residual feature 아이디어가 특히 영향력 있음

## 3. 벤치마크 포화 현황

| 벤치마크 | I-AUROC SOTA | 상태 | 의미 |
|---------|-------------|------|------|
| MVTec AD | 99.9% | **포화** | 더 이상 차별화 불가 |
| VisA | 99.3% | **거의 포화** | 미세 차이만 존재 |
| MVTec LOCO | 96.1% (SALAD) | **활성** | Logical anomaly가 핵심 도전 |
| Real-IAD | 90.1% | **활성** | 극소 결함, 실환경 난이도 |
| MVTec AD 2 | <60% AU-PRO | **매우 어려움** | 투명체, 극소결함, 조명변화 |
| Real-IAD Variety | - | **신규** | 160 카테고리, 스케일 도전 |
| MMAD | - | **신규** | MLLM 평가 전용 |

**핵심 관찰**: MVTec AD/VisA에서의 성능 보고는 이제 의미가 제한적. **MVTec AD 2, Real-IAD, MVTec LOCO**가 실질적 벤치마크

## 4. 핵심 미해결 문제 (연구 기회)

### Gap 1: MVTec AD 2 — 현실적 조건에서의 붕괴
- SOTA가 AU-PRO 60% 미만. 투명 객체, 극소 결함, 조명 변화에 기존 방법 무력
- EfficientAD: 조명 변화 시 >10pp AU-PRO 하락
- **기회**: Robust한 feature representation 또는 조명/도메인 불변 방법

### Gap 2: Logical Anomaly — 구조적 추론 부재
- 텍스처 결함은 해결됨, but 구성요소 누락/배치 오류는 ~96%
- VLM reasoning (LogicQA 87.6%)과 vision 방법 (SALAD 96.1%) 사이 격차
- **기회**: Vision + Language reasoning 통합, graph/relational 모델링

### Gap 3: 스케일링 — 카테고리 수 증가 시 성능 저하
- 30 → 160 카테고리에서 10-20% 성능 저하 (Real-IAD Variety)
- 실제 공장은 수백 카테고리 가능
- **기회**: Scalable unified representation, efficient memory/routing

### Gap 4: Noisy Training Data
- 현실에서 완벽한 정상 데이터 확보 불가 (불량품 혼입)
- SoftPatch, FUN-AD 등 시도 있으나 체계적 해결 미흡
- **기회**: Noise-robust learning, self-cleaning 메커니즘

### Gap 5: 평가 메트릭 부재
- AUROC는 threshold-free → 실 배치 의사결정 반영 못함
- Per-defect detection rate, false alarm cost, robustness metric 부재
- **기회**: 실용적 평가 프레임워크 제안

### Gap 6: 3D/Multimodal Foundation Model 부재
- 2D에서 DINOv2/CLIP의 성공을 3D에서 재현할 backbone이 없음
- **기회**: 3D anomaly detection 전용 foundation feature 또는 2D-3D 효과적 fusion

### Gap 7: Continual/Incremental AD
- 새 제품 추가 시 기존 제품 성능 보존 문제
- One-for-More (CVPR 2025), MECAD, CADIC 등 초기 시도
- **기회**: Parameter-efficient adaptation, replay-free continual learning

### Gap 8: Video AD in Manufacturing
- 산업 비디오 AD 벤치마크/방법론 거의 부재 (감시 영상 중심)
- **기회**: 생산 라인 특화 temporal anomaly detection

## 5. 2025-2026 예상 트렌드

1. **Foundation Model 통합 심화**: DINOv2 + CLIP + MLLM의 계층적 결합
2. **Anomaly Reasoning**: Detection 넘어 "왜"를 설명하는 방향 가속
3. **MVTec AD 2 중심 경쟁**: 새로운 hard benchmark로 전환
4. **AD 전용 Pretraining**: ADPretrain (NeurIPS 2025)을 시작으로 domain-specific pretraining
5. **Anomaly Synthesis 고도화**: Diffusion 기반 realistic/controllable 생성
6. **ADFM Workshop (CVPR 2026)**: Foundation model + AD가 공식 연구 테마로 확립
